# CI/CD Pipeline Templates

Reusable pipeline templates for GitHub Actions & GitLab CI.

## Templates
- `node-ci.yml` — Node.js lint, test, build, deploy
- `python-ci.yml` — Python pytest, lint, coverage
- `docker-build.yml` — Multi-stage Docker build & push
- `deploy-ecs.yml` — Deploy to AWS ECS

## Usage
Copy the template to `.github/workflows/` and customize variables.
